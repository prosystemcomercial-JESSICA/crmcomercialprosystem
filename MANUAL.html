1. 🎯 Visão Geral

O CRM Comercial ProSystem é uma plataforma completa para gestão de churn e retenção de clientes, desenvolvida especificamente para o setor de varejo (farmácias, padarias e lojas).

Objetivos Principais

🎯 Identificar Risco

Score automático de 0-100 para detectar clientes em risco de cancelamento

🔍 Diagnosticar Causas

Análise dos motivos reais que levam ao churn baseada em dados

📋 Planejar Ações

Criar planos personalizados de retenção com ações específicas

📊 Medir Resultados

Dashboard executivo com KPIs de recuperação e retenção

💡 Setor Foco: Varejo especializado da ProSystem (farmácias, padarias, lojas de varejo) que utilizam sistemas ERP e PDV.

3. ⚙️ Instalação e Setup

Pré-requisitos

  • Node.js 20+ (LTS)
  • npm 10+
  • Docker Desktop (para PostgreSQL)
  • Git (para versionamento)

Passo a Passo

1️⃣ Subir o banco de dados

cd backend
docker-compose up -d

2️⃣ Instalar dependências do Backend

cd backend
npm install
npx prisma generate
npx prisma db push
npx tsx prisma/seed.ts

3️⃣ Instalar dependências do Frontend

cd frontend
npm install

4️⃣ Iniciar os servidores

# Terminal 1 - Backend
cd backend
npm run dev

# Terminal 2 - Frontend
cd frontend
npm run dev
✅ Pronto! Acesse http://localhost:3000 para usar o sistema.

Cálculo do Risk Score

📐 Algoritmo de Risk Score (0-100):

O score é calculado em 5 dimensões com pesos diferentes:

  • Dias sem interação (peso 30%) — 0-30 pontos
  • Valor mensal contratado (peso 20%) — 0-20 pontos
  • Frequência de chamados no suporte (peso 20%) — 0-20 pontos
  • Tempo como cliente (peso 15%) — 0-15 pontos
  • Motivo reportado (peso 15%) — 0-15 pontos
FaixaClassificaçãoAção Recomendada
0-30🟢 BAIXOManter monitoramento padrão
31-70🟡 MÉDIOIniciar diagnóstico preventivo
71-100🔴 ALTOAção imediata - escalada para CEO

7. ⚡ Funcionalidades Principais

7.1 Dashboard Executivo

Visão geral em tempo real dos indicadores chave:

  • KPI Cards: Total de casos, Taxa de Diagnóstico, Taxa de Planejamento, Taxa de Recuperação
  • Distribuição de Risco: Gráfico de barras BAIXO / MÉDIO / ALTO
  • Casos Recentes: Tabela com últimos 10 casos abertos
  • Valor em Risco: Soma do valor mensal dos clientes em risco

7.2 Status dos Casos

StatusDescrição
NOVOCaso criado, aguardando diagnóstico
DIAGNOSTICADOAnálise concluída, motivos identificados
PLANEJADOPlano de retenção criado
EXECUTANDOAções em andamento
RECUPERADO✅ Cliente retido com sucesso
PERDIDO❌ Cliente cancelou

7.3 Tipos de Ação

  • CONTATO: Ligação ou reunião com o cliente
  • EMAIL: Envio de proposta ou comunicação
  • DESCONTO: Aplicar desconto na renovação
  • PRODUTO: Demonstração ou upgrade
  • OUTRO: Ações personalizadas

9. 🔧 Troubleshooting

Problemas Comuns

❌ Backend não inicia (port 3001 em uso)

# Windows PowerShell
Get-NetTCPConnection -LocalPort 3001 | Select-Object OwningProcess
Stop-Process -Id <PID> -Force

❌ Database connection failed

cd backend
docker-compose ps  # Verificar se postgres está rodando
docker-compose restart postgres

❌ Frontend mostra erro 500

Verifique se o backend está rodando em http://localhost:3001/health

❌ Login falha com "jwt.sign is not a function"

Reinstale o jsonwebtoken: cd backend && npm install jsonwebtoken

❌ Tests E2E falhando

cd frontend
npx playwright install chromium
⚠️ Em Produção: Sempre altere as variáveis JWT_SECRET e JWT_REFRESH_SECRET antes de fazer deploy. Use valores aleatórios de no mínimo 64 caracteres.

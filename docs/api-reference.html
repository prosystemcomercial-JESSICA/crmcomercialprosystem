🔐 Autenticação

JWT + Refresh Token em cookie httpOnly

Fluxo de Autenticação

Todas as rotas (exceto POST /api/auth/login) exigem o header Authorization: Bearer <token>. O token JWT expira em 15 minutos. Use o refresh token para renovar.

POST /api/auth/login Autenticar usuário

Body:

"email": "usuario@prosystemnet.com.br",
"senha": "senha123"

Response 200:

"accessToken": "eyJ...",
"user": { "id": "...", "name": "...", "perfil": "VENDEDOR" }
// refreshToken via cookie httpOnly (7 dias)

Erros: 401 Credenciais inválidas · 401 Conta bloqueada (5 tentativas = 15 min)

POST /api/auth/refresh Renovar access token

Usa o cookie refreshToken enviado automaticamente pelo browser. Retorna novo accessToken.

Response 200: {"accessToken": "eyJ..."}

Erros: 401 Token inválido ou expirado

POST /api/auth/logout Encerrar sessão

Revoga o refreshToken no banco e limpa o cookie. Requer autenticação.

Response: 204

👤 Leads

Módulo core — gestão completa de oportunidades comerciais

Filtro automático por role: VENDEDOR retorna apenas seus leads. SUPERVISAO/CEO/ADMIN retornam todos. Implementado no service.
GET /api/leads Listar leads com filtros
Todos os perfis

Query params: status segmento temperatura vendedorId origem parados=true followupVencido=true search page=1 limit=25

Response 200:

{ "data": [ {...lead} ], "total": 84, "page": 1, "pages": 4 }
POST /api/leads Criar lead
Todos os perfis

Body obrigatório:

CampoTipoNotas
empresa *stringou responsavel — um dos dois
telefone *string
whatsapp *string

Todos — VENDEDOR só seus leads

⚠️ Códigos de Status HTTP

StatusQuando ocorre
200 OKRequisição bem-sucedida com body
201 CreatedRecurso criado com sucesso
204 No ContentOperação bem-sucedida sem body (DELETE, logout)
400 Bad RequestDados inválidos no body ou query params
401 UnauthorizedToken ausente, expirado ou inválido
403 ForbiddenRole sem permissão para a operação
404 Not FoundRecurso não encontrado
409 ConflictConflito (ex: regra de comissão duplicada, parceiro com indicações)
422 Unprocessable EntityCampos obrigatórios da etapa do funil faltando — retorna lista de campos

Formato de Erro

{
  "statusCode": 422,
  "message": "Campos obrigatórios para a etapa QUALIFICACAO",
  "campos": ["sistemaAtual", "dorPrincipal", "planoSugerido"]
}

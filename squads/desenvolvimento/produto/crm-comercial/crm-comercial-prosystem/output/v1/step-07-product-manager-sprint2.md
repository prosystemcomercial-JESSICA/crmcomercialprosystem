# Step 07 — André Vieira (Product Manager)
# Sprint 2: Módulo de Usuários e Permissões

## User Stories

US-101 Criar usuário (Admin): nome + email + cargo + perfil + senha temporária
US-102 Permissões por perfil: tabela vendedor/supervisao/ceo/admin x ações
US-103 Editar usuário (Admin)
US-104 Inativar/reativar sem perder histórico
US-105 Login com JWT + bloqueio após 5 tentativas
US-106 Primeiro acesso: redefinir senha temporária
US-107 Meu Perfil: editar dados pessoais

## Perfis

- vendedor: acesso restrito aos próprios dados
- supervisao: acesso a toda a equipe + redistribuição
- ceo: acesso gerencial + relatórios + sem criação de leads
- admin: acesso total + configurações + usuários

## Telas para UX

Login | Lista de Usuários | Formulário Usuário | Meu Perfil | Redefinir Senha
